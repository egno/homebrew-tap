# egno/tap

Homebrew casks by egno.

```sh
brew install --cask egno/tap/foci
brew install --cask egno/tap/progradio
```

| Cask | What |
|---|---|
| [`foci`](Casks/foci.rb) | [Foci](https://github.com/egno/foci): keyboard-first macOS window manager for working on one project at a time |
| [`progradio`](Casks/progradio.rb) | [Prog Radio](https://github.com/egno/progradio): menu bar player for progradio.com with widgets and a Control Center control |

Each cask is generated by `make cask` in its app's repo.
